# BestMiniPython
Based on Python for Windows 1.3, this is a Python interpreter with a complete CPython implementation.

## Stats
Raw files:
- `python.exe`: 3,584 bytes
- `py130-2.dll`: 280,064 bytes
Raw total: ~277KB
Archive: RAR5 solid best compression → **105KB**

## Features
- Full original CPython 1.3 REPL interactive console
- Variables, integer arithmetic, string support
- Function definition with `def`
- `if` / `while` / `for` control flow
- Built-in `sys` module
- No `lib` folder, zero extra dependencies

## Syntax Note
`print` is a **statement**, not a function.
```python
print "Hello BestMiniPython!"
